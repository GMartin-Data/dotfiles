# Report Template

Filename: `tech-watch-{query}-{YYYY-MM-DD}.md`

---

```markdown
# Tech Watch — {query}
**Date**: {YYYY-MM-DD} | **Window**: {days_back} days | **Sources**: {n}

---

## Executive Summary
[2–3 sentences. Answer: what is the dominant trend? Any unexpected findings?
Do NOT list sources here — synthesize across them.]

---

## Primary sources

[1–3 entries from the topic owner (official docs, announcement, reference repo or spec),
outside the ranking: no score, no threshold, no cap. If none exists, write
"No primary source found for this topic." and say what was searched.]

**{Title}** — 🔗 {URL} — 📅 {publication_date | unverified}
{one line: what this source establishes (version, availability, requirements)}

---

## Sources ranked by score

[Group by tier/score band using the labels from scoring-criteria.md.
Within each group, order by score descending.]

---

### 🔴 Essential (score 85–100)

**[N] {Title}**
🔗 {URL}
📅 {publication_date | unverified} | ⭐ Authority: High/Medium/Low/unverified | 📊 Score: {score}/100
**Summary**: {2–3 sentences — what makes this source specifically relevant to the query}
**Score reason**: {one line from scoring-criteria.md}
**Tags**: `{tag1}`, `{tag2}`, `{tag3}`

---

### 🟠 High value (score 70–84)

[same format]

---

### 🟡 Worth including (score 60–69)

[same format]

## Trends identified

[3–5 bullet points. Patterns observed ACROSS sources, not summaries of individual ones.

---

*Generated by tech-watch skill | Sources: arXiv · GitHub · YouTube · Web search*
*Scoring: Relevance 40% · Freshness 20% · Authority 20% · Depth 10% · Engagement 10%*
```

`unverified` is the only allowed value for a date, length or authority that could not be established (SKILL.md, step 8). Never estimate one.
